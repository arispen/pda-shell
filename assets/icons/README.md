# Shell icons

Original icons drawn for pda-shell (POC 0.3): flat shapes on a 48×48 grid
with a dark outline and a vertical gradient, in the spirit of early-2000s
PDA icons. They are not derived from Microsoft, Windows Mobile or any other
third-party artwork; the Start emblem is deliberately not a flag.

License: the project's license (MIT OR Apache-2.0).

The shell loads them by name (`pda-today`, `pda-calendar`, …) from, in
order, `$PDA_SHELL_ICONS`, `/usr/share/pda-shell/icons`, or this directory.
Program icons come from the installed programs themselves.
